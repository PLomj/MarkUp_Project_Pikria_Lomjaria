# Satoshi fonts

Original source: https://www.fontshare.com/fonts/satoshi

Official download: https://api.fontshare.com/v2/fonts/download/satoshi

Downloaded on 2026-11-08. The included `FFL.txt` is the license supplied in the official archive.

Local webfont files prepared for Desktop Home and Mobile Dark Home:

| File | Weight | Style |
| --- | --- | --- |
| Satoshi-Regular.woff2 | 400 | Normal |
| Satoshi-Medium.woff2 | 500 | Normal |
| Satoshi-Bold.woff2 | 700 | Normal |

These are unmodified WOFF2 files from the official package. The project does not load them yet.

The license permits self-hosting for the licensee's own websites, but restricts redistribution through repositories. The font binaries are therefore excluded from Git. Anyone setting up another copy of this project should obtain the files directly from Fontshare and place the three files here.

Figma artwork and icons have not been saved: the connected Starter plan currently blocks asset reads and exports because its MCP call limit has been reached. No substitute assets have been added.
